# F1 Podium Prediction

Predicting whether a driver finishes on the podium using grid position,
constructor, circuit and recent form.

## Data
[Formula 1 World Championship (Kaggle)](https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020).
Download and unzip into a `data/` folder.
